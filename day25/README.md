## 1장. 개념 이해하기

멱등성을 확인하려면 건수뿐 아니라 키와 값도 비교해야 한다. 두 번째 실행에서 기존 가격을 잘못 덮어써도 건수는 같을 수 있다. 수정 입력과 같은 입력을 구분하고 각 경우의 목표 상태를 먼저 정한다.

오늘은 성공·재실행·수정·실패를 같은 인터페이스로 검증한다. 임시 표만으로 끝내지 말고 실습용 영구 표의 커밋 결과를 새 연결에서도 확인한다. 원본 배치 이력과 정제 표의 행 수가 다를 수 있는 이유도 기록한다.

## 2장. 실습 준비

4주 차 가상환경에 `.\.venv\Scripts\python.exe -m pip install "psycopg[binary]"`로 드라이버를 설치한다. PowerShell에서 `$env:DE_DSN="host=127.0.0.1 port=5433 dbname=market_db user=de_user password=de_password"`를 설정한다. 로컬 전용 연결값이며 실제 비밀값은 저장하지 않는다. Python 블록은 dayNN/practice.py로 저장해 가상환경 Python으로 실행한다.

이전 학습일의 과제를 아직 구현하지 않았다면 해당 교재에서 먼저 준비한다. 문서 안의 파일명은 앞으로 작성할 산출물을 포함한다. 첫 사용 환경은 이번 주 첫 교재인 [Day 21](../day21/README.md)의 준비 항목도 확인한다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```python
import os
import psycopg

with psycopg.connect(os.environ["DE_DSN"]) as conn:
    rows = conn.execute("""
        SELECT symbol, trade_date, close_price
        FROM raw_market_prices ORDER BY id
    """).fetchall()
    print("raw_rows=", len(rows))
    print("business_keys=", len({(s, d) for s, d, _ in rows}))
```

**예상 결과와 확인 기준:** 최초 Raw는 5행·업무 키 4개다. 이것은 진단 예제이며 적재 검증은 직접 구현한 목표 표에서 수행한다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.

## 4장. 직접 해볼 실습 과제

1. 동일 구간 2회 실행 후 정제 행의 키·가격을 정렬해 비교한다.
2. 수정 가격 1건과 중간 실패를 각각 넣고 기대 상태·Watermark와 대조한다.
3. 실행 명령·DDL·원본 이력 정책·복구 절차를 묶어 5주 실행 안내를 완성한다.

작성한 코드·SQL·설정은 이 day 폴더 또는 과제에서 지정한 공통 디렉터리에 저장한다. 실행 기록은 `day25/notes.md`에 남긴다. 원본 예제와 별도 경로를 사용하고, 오류 입력·재실행으로 결과가 달라졌다면 그 이유도 기록한다.

## 5장. 막혔을 때 확인하기
