## 1장. 개념 이해하기

JSON은 배열·객체·숫자·null을 표현하고 CSV는 행과 문자열 열을 표현한다. CSV의 빈칸을 NULL로 볼지 빈 문자열로 볼지는 읽는 쪽에서 정해야 한다. 가격을 float로 읽으면 이진 부동소수점 오차가 생길 수 있어 Decimal과 문자열 저장을 사용한다.

경로는 현재 작업 폴더에 따라 달라질 수 있다. Path(__file__)로 스크립트 위치를 기준 삼거나 입력 경로를 인자로 받으면 재현하기 쉽다. 저장할 때 UTF-8과 열 이름도 명시한다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```python
import csv
import io
import json
from decimal import Decimal

source = io.StringIO("symbol,date,close\nQQQ,2026-10-26,620.50\n")
row = next(csv.DictReader(source))
row["close"] = str(Decimal(row["close"]))
print(json.dumps(row, ensure_ascii=False))
```

**예상 결과와 확인 기준:** symbol·date·close가 있는 JSON 한 행이며 가격은 문자열 620.50으로 유지된다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.
