## 1장. 개념 이해하기

GROUP BY는 같은 종목의 여러 거래일을 한 묶음으로 만든다. COUNT는 건수, AVG는 평균을 계산한다. 집계하면 원래의 개별 거래일 정보는 결과에서 사라지므로 어떤 단위로 보고 싶은지 먼저 정해야 한다.

WHERE는 집계 전에 행을 제한하고 HAVING은 집계한 그룹을 제한한다. 예를 들어 가격 650 초과인 행만 고르는 것과 평균 가격이 650 초과인 종목을 고르는 것은 다른 질문이다. COUNT(*)와 COUNT(열)은 NULL을 세는 방식도 다르다.

## 2장. 실습 준비

Day 2의 PostgreSQL에 접속한다. 아래 `WITH prices ... VALUES` 예제는 원본 테이블과 독립적인 가상 가격 4건이다. CTE는 해당 문장에서만 존재하므로 SQL 블록 전체를 실행한다. 직접 작성할 쿼리는 `sql/week02/`에 저장한다.

이전 학습일의 과제를 아직 구현하지 않았다면 해당 교재에서 먼저 준비한다. 문서 안의 파일명은 앞으로 작성할 산출물을 포함한다. 첫 사용 환경은 이번 주 첫 교재인 [Day 6](../day06/README.md)의 준비 항목도 확인한다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```sql
WITH prices(symbol, trade_date, close_price) AS (
    VALUES ('QQQ', DATE '2026-10-26', 620.50::numeric),
           ('SPY', DATE '2026-10-26', 680.20::numeric),
           ('QQQ', DATE '2026-10-27', 621.00::numeric),
           ('SPY', DATE '2026-10-27', 682.00::numeric)
)
SELECT symbol, COUNT(*) AS days, AVG(close_price) AS avg_price
FROM prices GROUP BY symbol
HAVING COUNT(*) >= 2 ORDER BY symbol;
```

**예상 결과와 확인 기준:** QQQ와 SPY가 각각 2건이며 평균은 620.75와 681.10이다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.

## 4장. 직접 해볼 실습 과제

1. 종목별 최솟값과 최댓값을 추가한다.
