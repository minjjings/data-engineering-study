# Day 42. is_incremental과 지연 데이터 범위

**9주 차 · 주간 2일차 | 약 90~120분**

[전체 계획](../README.md) · [120일 목차](../README.md#day-index) · [← Day 41](../day41/README.md) · [Day 43 →](../day43/README.md)

이번 주에는 **dbt 증분 모델과 Airflow 연결** 내용을 다룬다. 오늘은 겹쳐 읽는 구간으로 최근 수정 데이터를 다시 반영한다.

> 미리 작성한 교재다. 아래 예제·예상 결과는 학습 기준이며 실행을 완료했다는 뜻은 아니다. 과제에서 요구하는 코드·설정·결과는 직접 작성한다. 시장 가격은 가상 데이터다.

## 오늘의 학습 목표

- 겹쳐 읽는 구간으로 최근 수정 데이터를 다시 반영한다.
- 예제의 입력과 결과를 비교하고 처리 기준을 자기 말로 설명한다.
- 직접 작성한 과제와 실행 근거를 남긴다.

| 순서 | 할 일 | 예상 시간 |
| --- | --- | --- |
| 1 | 개념과 준비 항목 확인 | 20분 |
| 2 | 예제 실행·입출력 확인 | 25~35분 |

| 4 | 결과 기록과 리뷰 | 15~20분 |

## 1장. 개념 이해하기

is_incremental은 기존 목표 표가 있고 full-refresh가 아닌 증분 실행일 때 참이다. 새 표 생성 경로에서는 목표 표를 읽으면 안 된다. 최대 거래일만 초과하는 필터는 과거 수정을 놓치므로 최근 며칠을 겹쳐 읽는 방법을 비교한다.

## 2장. 실습 준비

기존 dbt 프로젝트를 사용하며 `seeds/incremental_input.csv`에 symbol,trade_date,close_price 헤더와 QQQ,2026-10-26,620.50 및 SPY,2026-10-26,680.20 두 행을 준비한다. Day 41~44에서는 이 seed를 바꾸며 실험한다. Airflow 연동은 Worker 이미지 안에도 같은 dbt 어댑터·프로젝트·profile을 배치해야 한다.

이전 학습일의 과제를 아직 구현하지 않았다면 해당 교재에서 먼저 준비한다. 문서 안의 파일명은 앞으로 작성할 산출물을 포함한다. 첫 사용 환경은 이번 주 첫 교재인 [Day 41](../day41/README.md)의 준비 항목도 확인한다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```sql
-- Day 41 SELECT 뒤에 추가한다.
{% if is_incremental() %}
WHERE trade_date::date >= (
    SELECT COALESCE(MAX(trade_date), DATE '1900-01-01') - 2
    FROM {{ this }}
)
{% endif %}
```

**예상 결과와 확인 기준:** 목표 최대 거래일보다 2일 이전부터 다시 읽는다. 그보다 오래된 수정은 반영하지 못할 수 있다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.

## 4장. 직접 해볼 실습 과제

1. seed에 다음 거래일과 최근 거래일 수정 가격을 추가해 반영을 확인한다.
2. 범위 밖 과거 날짜 수정이 누락되는 사례를 만든다.
3. 날짜가 같은 여러 행은 증분 입력 단계에서 결정적으로 중복 제거한다.

작성한 코드·SQL·설정은 이 day 폴더 또는 과제에서 지정한 공통 디렉터리에 저장한다. 실행 기록은 `day42/notes.md`에 남긴다. 원본 예제와 별도 경로를 사용하고, 오류 입력·재실행으로 결과가 달라졌다면 그 이유도 기록한다.

## 5장. 막혔을 때 확인하기

SQL 실행 위치를 확인한다. 일반 PostgreSQL SQL은 psql에서, Athena SQL은 Athena에서, Jinja가 있는 모델 SQL은 dbt 모델 파일에서 실행한다. TEMP 테이블은 생성한 연결에서만 보인다.

예상 건수와 다르면 사용한 입력·필터·기존 상태부터 비교한다. 해결하지 못한 오류는 입력과 실행 명령, 오류 메시지를 함께 남긴다.
