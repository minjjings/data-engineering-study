## 1장. 개념 이해하기

DB 드라이버는 Python 프로그램과 PostgreSQL 사이에서 쿼리와 결과를 전달한다. 연결 주소·포트는 프로그램이 실행되는 위치 기준이다. 호스트에서는 127.0.0.1:5433이지만 컨테이너 안의 localhost는 그 컨테이너 자신이다.

매개변수는 SQL 구조와 값을 분리한다. f-string으로 값에 따옴표를 붙이지 않고 execute의 두 번째 인자로 전달한다. 테이블 이름은 값 매개변수가 아니므로 동적 식별자가 필요하면 드라이버의 Identifier 기능을 사용한다.

## 2장. 실습 준비

4주 차 가상환경에 `.\.venv\Scripts\python.exe -m pip install "psycopg[binary]"`로 드라이버를 설치한다. PowerShell에서 `$env:DE_DSN="host=127.0.0.1 port=5433 dbname=market_db user=de_user password=de_password"`를 설정한다. 로컬 전용 연결값이며 실제 비밀값은 저장하지 않는다. Python 블록은 dayNN/practice.py로 저장해 가상환경 Python으로 실행한다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```python
import os
import psycopg

with psycopg.connect(os.environ["DE_DSN"]) as conn:
    with conn.cursor() as cur:
        cur.execute("SELECT symbol, close_price FROM raw_market_prices WHERE symbol = %s", ("QQQ",))
        print(cur.fetchall())
```

**예상 결과와 확인 기준:** 최초 Raw 기준 QQQ 3건이 반환된다. 조회 순서는 ORDER BY가 없으므로 고정하지 않는다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.

## 4장. 직접 해볼 실습 과제

1. symbol을 인자로 받아 QQQ·SPY를 각각 조회한다.

3. 잘못된 포트로 접속해 연결 실패와 쿼리 실패를 구분해 기록한다.
