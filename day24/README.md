## 1장. 개념 이해하기

현재 날짜를 함수 내부에서만 계산하면 과거 구간을 재현하기 어렵다. 시작일 포함·종료일 제외인 반열린 구간을 인자로 받으면 인접한 배치의 경계가 겹치지 않는다. 거래일 기준과 수집 시각 기준도 이름으로 구분한다.

이번 배치의 상한은 실행 시작 때 고정하고 적재·상태 갱신을 함께 커밋한다. 명시적인 날짜 재처리는 자동 증분 상태를 무작정 덮어쓰지 않게 별도 경로로 둔다.

## 3장. 예제로 따라 해보기

먼저 예상 결과를 읽고 어떤 입력이 어떤 이유로 남는지 생각한다. 아래 코드가 부분 예제라면 주석에서 지정한 파일·함수·이전 코드에 합친다.

```python
import argparse
from datetime import date

parser = argparse.ArgumentParser()
parser.add_argument("--start", type=date.fromisoformat, required=True)
parser.add_argument("--end", type=date.fromisoformat, required=True)
args = parser.parse_args()
if args.start >= args.end:
    parser.error("start must be before end")
print(args.start <= date(2026, 10, 26) < args.end)
```

**예상 결과와 확인 기준:** `--start 2026-10-26 --end 2026-10-27`을 붙이면 True다. 같은 시작·종료일은 오류 종료한다.

화면 출력이나 성공 상태만으로 끝내지 않고, 오늘 목표와 직접 연결되는 건수·키·값·상태를 확인한다.
